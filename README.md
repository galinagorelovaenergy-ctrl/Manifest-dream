# Manifest — Создай мечту

Лендинг и веб-приложение для осознанной материализации: дневник желаний, состояние дня, диалог с «будущим собой» и визуализация.

## Быстрый старт

Откройте `index.html` в браузере — сервер не обязателен.

```bash
# опционально: локальный сервер
npx serve .
```

## Структура

```
├── index.html      # лендинг + приложение
├── css/main.css    # стили
├── js/app.js       # логика и localStorage
└── README.md
```

## Возможности

- **Дневник желаний** — записи с категориями, сохранение в `localStorage`
- **Состояние дня** — выбор энергии и подсказка
- **Future Self Chat** — диалог с ответами «будущей версии»
- **Визуализация** — дыхательный круг и аффирмация

## Технологии

Статический HTML, CSS и JavaScript без сборки.
